# GLSL ( OpenGL Shading Language ) 문법

| 코드 | 종류 | 역할 |
|---|---|---|
| `attribute` | 한정자 | 외부 버퍼의 정점 데이터를 VS에서 받는다 |
| `varying` | 한정자 | VS의 값을 FS로 전달한다 |
| `precision` | 설정문 | 실수의 기본 계산 정밀도를 정한다 |
| `float` | 자료형 | 실수 한 개를 저장한다 |
| `vec2` | 자료형 | 실수 2개를 저장한다 |
| `vec3` | 자료형 | 실수 3개를 저장한다 |
| `vec4` | 자료형 | 실수 4개를 저장한다 |
| `void main()` | 시작 함수 | GPU가 자동으로 실행하는 함수다 |
| `gl_Position` | 내장 변수 | 정점의 최종 위치를 출력한다 |
| `gl_FragColor` | 내장 변수 | 픽셀의 최종 색상을 출력한다 |
| `mix()` | 내장 함수 | 두 값을 비율에 따라 섞는다 |
