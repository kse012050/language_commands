# 이벤트 전파
이벤트 전파(Event Propagation)는 DOM 트리에서 이벤트가 발생했을 때, 이벤트가 상위 또는 하위 요소로 __이동__ 되는 과정입니다.  
중요한 것은 __이벤트가 전파되더라도 이벤트 핸들러가 등록된 곳에서만 이벤트가 처리된다는 것__ 입니다.  
이벤트 자체는 전파되지만, 실제로 이벤트를 실행하려면 해당 요소에 이벤트 핸들러가 있어야 합니다.

## 이벤트 전파 과정
### 캡처링 단계 ( Capturing Pase )
이벤트가 __최상위 요소__ 에서 __이벤트 발생한 요소까지 내려가면서__ 전파되는 단계입니다.  
상위에서 하위로 이동하는 과정입니다

### 타깃 단계 ( Target Phase )
이벤트가 __실제로 발생한 요소__ 에서 이벤트가 처리되는 단계입니다.  
이 요소를 __이벤트 타깃__ 이라고 합니다.

### 버블링 단계 ( Bubbling Phase )
이벤트가 발생한 요소에서 __상위 요소로 전파되는 단계__ 입니다.  
하위에서 상위로 올라가는 과정입니다.


## e.stopPropagation()
이벤트 전파되는 것을 막습니다.  
중요한 것은 전파되는 걸 막는 것이기 때문에 해당 이벤트까지는 전달이 됩니다.

## e.preventDefault()
기본 값 방지 a, form, input key, drggable, contextmenu 등이 있습니다.

## e.stopImmediatePropagation()
__이벤트의 전파를 둥단하고, 동일한 요소에 연결된 다른 빈테 핸들러들의 실행을 막는__ 메서드 입니다.  
e.stopPropagation()은 이벤트 전파를 막아서 상위 요소로의 이벤트 버블링을 멈추지만, __동일한 요소에 연결된 다른 이벤트 핸들러들은 여전히 실행됩니다__  
  
__event.stopImmediatePropagation()__ 은 동일한 요소에 연결된 다른 모든 이벤트 핸들러의 실행도 중단합니다.
