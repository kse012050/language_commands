# 라이브러리 정리

## 권한 푸는방법
> __executionpolicy__  
> Resticted 가 뜨면 문제가 있는 것  
  
> __set-executionpolicy unrestricted__  
> 실행 규칙을 변경할 수 있다 'Y' 입력

## nodemon
저장시 서버를 자동으로 껐다 켜주는 기능

### 설치
> npm install -g nodemon

### 실행방법
> nodemon 파일명.확장자명

[내용 NPM package](https://www.npmjs.com/package/nodemon)

## body-parser
요청 데이터(body) 해석을 쉽게 도와줌

### 설치
> npm install body-parser  

### 사용법
~~~html
<input type="text" name="userName">
<!-- name 속성을 꼭 써줘야한다 -->
~~~
~~~js
// 구버전
const bodyParser = request('body-parser');
app.use(bodyParser.urlencoded({extended: true})) 

// 2021년 이후
// 설치 필요없이 (npm에 포함되어있다)
app.use(express.urlencoded({extended: true})) 
~~~

## EJS
HTML에 데이터를 넣을 때 쫌 더 편하게 할 수 있게 도와주는 라이브러리  
ejs 파일들은 views 폴더에 있어야 한다
### 설치
> npm install ejs

### 사용법
~~~js
app.set('view engine', 'ejs');
~~~

#### 파일.ejs
ejs 파일들은 views 폴더에 있어야 한다
HTML이랑 똑같지만 php 처럼 서버 데이터를 넣을 수 있다
~~~html
<div><%= 변수이름 =></div>
~~~

### 실제사용
~~~js
const express = require('express');
const app = express();
app.use(express.urlencoded({extended: true})) 
const MongoClient = require('mongodb').MongoClient;
app.set('view engine', 'ejs');


var db;
MongoClient.connect('mongodb+srv://admin:3125@cluster0.pztdx.mongodb.net/?retryWrites=true&w=majority', function(에러 , client){
    // 연결되면 할일
    if(에러){return console.log(에러)}
    db = client.db('todoapp');
    app.listen(8080, function(){
        console.log('listening on 8080');
    });
    
})

app.get('/list',function(요청 , 응답){
    // 디비에 저장된 post라는 collection안의 모든 데이터를 꺼내주세요
    db.collection('post').find().toArray(function(에러 , 결과){
        console.log(결과);
        응답.render('list.ejs', { posts : 결과});
    });
})
~~~

#### list.ejs
ejs 파일들은 views 폴더에 있어야 한다
~~~html

</body>
</html>
~~~
