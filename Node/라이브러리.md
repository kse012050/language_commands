# 라이브러리 정리

## 권한 푸는방법
> __executionpolicy__  
> Resticted 가 뜨면 문제가 있는 것  
  
> __set-executionpolicy unrestricted__  
> 실행 규칙을 변경할 수 있다 'Y' 입력

## nodemon
저장시 서버를 자동으로 껐다 켜주는 기능

### 설치
> npm install -g nodemon

### 실행방법
> nodemon 파일명.확장자명

[내용 NPM package](https://www.npmjs.com/package/nodemon)

## body-parser
요청 데이터(body) 해석을 쉽게 도와줌

### 설치
> npm install body-parser  

### 사용법
~~~html
<input type="text" name="userName">
<!-- name 속성을 꼭 써줘야한다 -->
~~~
~~~js
// 구버전
const bodyParser = request('body-parser');
app.use(bodyParser.urlencoded({extended: true})) 

// 2021년 이후
// 설치 필요없이 (npm에 포함되어있다)
app.use(express.urlencoded({extended: true})) 
~~~
