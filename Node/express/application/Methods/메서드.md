# 메서드 간단 정리

## app.use()
모든 요청에 대해 미들웨어 처리  
글로벌 미들웨어 설정, 정적 파일 제공 등

## app.get()
GET 요청에 대한 라우팅  
데이터 조회, 웹 페이지 렌더링 등

## app.post()
POST 요청에 대한 라우팅  
데이터 전송, 폼 제출 등

## app.put()
PUT 요청에 대한 라우팅  
자원 전체 수정

## app.delete()
DELETE 요청에 대한 라우팅  
자원 삭제

## app.all()
모든 HTTP 메서드에 대한 라우팅  
모든 종류의 요청에 대해 처리

## app.head()
HEAD 요청에 대한 라우팅  
응답 헤더만 반환 (GET과 비슷)

## app.patch()
PATCH 요청에 대한 라우팅  
자원 부분 수정

[내용출처 express 공식사이트](https://expressjs.com/ko/api.html#app.all)
