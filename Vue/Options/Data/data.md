# 데이터
- Type (유형) : ``Object`` | ``Function``  
- Restriction (제한 사항) : ``function`` 컴포넌트 정의에서 사용 될 때만 허용 합니다.
- Details (세부) :  

Vue 인스턴스의 데이터 개체입니다. Vue는 속성을 getter/setter로 제귀적으로 변환하여 "반응" 상태로 만듭니다. __객체는 일반이어야합니다__. 브라우저 API 객체 및 프로토 타입 속성과 같은 기본 객체는 무시됩니다. 경험상 데이터는 데이터 여야한다는 것입니다. 자체 상태 기반 동작으로 객체를 관찰하는 것은 권장되지 않습니다.  
  
일단 관찰되면 더 이상 루트 데이터 개체에 반응 속성을 추가 할 수 없습니다. 따라서 인스턴스를 만들기 전에 모든 루트 수준 반응 속성을 미리 선언하는 것이 좋습니다.  

인스턴스가 생성 된 후 원본 데이터 객체는 ``vm.$data``. 뷰 인스턴스는 모든 속성이 있으므로, 데이터 객체에서 발견 프록시를 ``vm.a``에 해당 될 것입니다 ``vm.$data.a``.  
  
시작 속성 ``_`` 또는 ``$`` 것 __없는__ 그들이 뷰의 내부 속성과 API 방식과 충돌 할 수 있기 때문에 뷰 인스턴스 프록시 될 수 있다. ``vm.$data._property``으로 액세스 해야 합니다.  
  
결정적인 때 __구성 요소를__ , ``data`` 많은 경우 이 같은 정의를 사용하여 생성이되기 때문에, 초기 데이터 객체를 반환하는 함수로 선언해야 합니다. ``data`` 일반객체를 사용하면 ``data`` 동일한 객체가 생성된 모든 인스턴스에서 __참조__ 로 __공유됩니다!__  ``data`` 함수를 제공하면 새 인스턴스가 생성 될 때 마다 호출하여 초기 데이터의 새 복사본을 반환 할 수 있습니다.  
  
필요한 경우, 원본 객체의 깊은 클론 전달하여 얻을 수 있습니다 ``vm.$data`` 통해 ``JSON.parse(JSON.stringify(...))``
- Example (예) :
~~~js
var data = { a: 1 }

// 직접 인스턴스 생성
var vm = new Vue({
  data: data
})
vm.a // => 1
vm.$data === data // => true

// Vue.extend() 에서 함수를 사용해야합니다.
var Component = Vue.extend({
  data: function () {
    return { a: 1 }
  }
})
~~~
``data`` 속성과 함께 화살표 함수를 사용하는 경우 ``this``는 구성 요소의 인스턴스가 아니지만 함수의 첫 번째 인수로 인스턴스에 계속 엑세스 할 수 있습니다.
~~~js
data: vm =>({ a: vm.myProp })
