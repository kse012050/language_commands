# key
- 예상됨 : ``string`` , ``number | string | boolean (since 2.4.2) | symbol (since 2.5.12)``  
``key`` 특수 속성은 Vue의 가상 DOM 알고리즘이 새로운 노드 목록을 이전 목록과 비교할 때 Vnode를 식별하기 위한 힌드로 주로 사용됩니다. 키가 없으면 Vue는 엘리먼트 이동을 최소화하고 같은 유형의 엘리먼트를 최대한 많이 채피 / 재사용하려고 하는 알고리즘을 사용합니다. 키를 사용하면 키의 순서 변경을 기반으로 엘리먼트가 재정렬되고 더 이상 존재하지 않는 키가 있는 엘리먼트는 항상 제거 / 삭제 됩니다.  
  
동일한 부모의 자식 엘리먼트는 __고유 키__ 가 있어야 합니다. 키가 중복되면 랜더링 오류가 발생합니다.  
  
가장 일반적인 이용 사례는 ``v-for``와 결합합니다.

~~~html
<ul>
    <li v-for="item in items" :key="item.id">...</li>
</ul>
~~~

엘리먼트 / 컴포넌트를 재사용하지 않고 강제로 대체하는데에는 사용할 수 있습니다. 이것은 다음과 같은 경우 유용할 수 있습니다.  

- 컴포넌트의 라이프사이클 훅을 올바르게 트리거합니다.
- 트랜지션효과 호출  

예제 :
~~~html
<transition>
    <span :key="text">{{ text }}</span>
</transition>
~~~
``text``가 변경되면 ``<span>``는 패치가 아닌 교체되므로 드랜지션이 트리거됩니다.
