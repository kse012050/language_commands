# Vue
## introduction 소개 
Vue는 사용자 인터페이스를 구축하기 위한 __진보적 인 프레임 워크__ 입니다. 처음부터 점진적으로 채택 할 수 있도록 설계되었으며 다양한 사용 사례에 따라 라이브러리와 프레임 워크간에 쉽게 확장 할 수 있습니다. 뷰 레이어에만 집중하는 접근 가능한 코어 라이브러리와 대규모 단일 페이지 애플리케이션의 복잡성을 해결하는 데 도움이 되는 지원 라이브러리 에코 시스템으로 구성됩니다.

### Browser Compatibility 브라우저 호환성
Vue.js 는 __``ES5를 준수``__ 하는 모든 브라우저는 지원합니다. (IE8 이하는 지원되지 않음)
