# Vuex 기술 요소
- __state__ : 여러 컴포넌트에 공유되는 데이터 ``data``
> 기본 ES5 , vue 의 ``data`` 와 동일
- __getters__ : 연산된 state 값을 접근하는 속성 ``computed``
> 기본 ES5 , vue 의 ``computed`` 와 동일
- __mutations__ : state 값을 변경하는 이벤트 로직 · 메서드 ``methods``
> 기본 ES5 , vue 의 ``methods`` 와 동일
- __actions__ : 비동기 처리 로직을 선언하는 메서드 ``aysnc methods``
> 기본 ES5 , vue 의 ``aysnc methods`` 와 동일
