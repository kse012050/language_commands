# react 설치

## yarn 명렁어

### yarn create react-app [프로젝트 이름]
[프로젝트 이름]의 파일을 만들고 react를 설치한다

### yarn start
해당 프로젝트를 실행한다

### yarn build
만든 프로젝트를 빌더(파일들을 압축) 한다

### yarn test
작성한 유닛 테스트를 실행해서 테스트를 성공했는지 실패했는지 알려준다
> 유닛 테스트라는게 무엇을까..? 아직 모르겠다

### yarn eject
create-react-app 으로 react를 설치하면 많은 것들이 자동적으로 설정이 되어져 있고 숨겨져 있다  
자동으로 설정되어 있는 것들을 확인해 볼 수 있다

### yarn add [package]
package 추가
> __예__ : yarn add axios  
> __예__ : yarn add react-router-dom
