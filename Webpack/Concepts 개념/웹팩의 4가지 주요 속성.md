# 웹팩의 4가지 주요 속성
웹팩의 빌드(파일 변환) 과정을 이해하기 위해서는 아래 4가지 주요 속성에 대해서 알고 있어야 합니다.
- entry  
빌드를 할 대상 폴더를 지정하는 entry
- output  
빌드를 하고 나서(웹팩으로 변환한 파일의 정보) 결과물을 정의하는 output
- loader  
entry에서 output 으로 변환할 때, 개입하는 module
- plugin
