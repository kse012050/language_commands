# MySQL ( 관계형 데이터 베이스 )
Structured Query Language - 구조화된 쿼리 언어

## 간단 명령어 사용법 ( 데이터베이스 스키마 관련 )

### SHOW {DATABASES | SCHEMAS};
데이터베이스( 스키마 ) 목록을 보여준다

### USE 이름;
``이름``으로 된 데이터베이스( 스키마 )를 사용한다

### CREATE DATABASE 이름;
사용자가 지정한 ``이름``으로 데이터베이스( 스키마 )를 생성한다

### DROP DATABASE 이름;
``이름`` 으로 된 데이터 베이스( 스키마 )를 제거한다


## 간단 명령어 사용법 ( 데이터베이스 스키마안 테이블 관련 )

### SHOW TABLES;
데이터베이스 ( 스카마 )안에 있는 테이블 목록을 보여준다

### CREATE TABLE 이름( 옵션들 - 행, PRIMARY KEY(행 이름) );
사용자가 지정한 ``이름``으로 테이블을 만든다 ( 옵션은 나중에 정리 )
~~~dir
CREATE TABLE 테이블명 (
    id INT AUTO_INCREMENT PRIMARY KEY,
    필드명2 옵션,
    created TIMESTAMP DEFAULT CURRENT_TIMESTAMP
)
~~~

### RENAME TABLE 테이블명 TO 변경할 테이블명;
테이블의 이름을 변경한다

### DROP TABLE 이름;
``이름`` 으로 된 데이터 베이스( 스키마 )안 데이블을 제거한다

### DESC 테이블이름;
``테이블이름`` 테이블에 있는 데이터 항목을 보여 준다

### INSERT INTO 테이블이름 ( 데이터 명 ) VALUES( 데이터 값 );
``테이블이름`` 테이블에 데이터를 넣는다  
데이터명과 VALUES 값을 여러게 넣을 떄는 ``,`` 로 구분한다  
데이터 명 항목은 생략 가능 ( 데이터값도 생략, 즉 id 값 같이 자동으로 계산되는 값 제외 )  
테이터 값 ``NOW()``를 하면 현재 시간을 넣어준다
~~~dir
INSERT INTO 테이블이름 ( 데이터명1, 데이터명2 ) VALUES( 데이터값1, 데이터값2 );
~~~

### SELECT 데이터명 FROM 테이블이름;
``테이블이름`` 테이블에 데이터명 값들을 보여준다  
여러개의 데이터명을 가져올 땐 ``,`` 로 구분해서 넣어주면 되고 전체를 가져올 땐 ``*``을 사용하면 된다 

> __~~~___ 물결은 위의 명령어 뒤에 이어서 붙여주면 된다

#### ~~~ WHERE 데이터명='데이터값';
``테이블이름`` 테이블에서 데이터명의 조건이 맞는 항목들을 보여준다

#### ~~~ ORDER BY 데이터값 정렬순서
``테이블이름`` 테이블에서 ``데이터명``의 데이터값 으로 ``정렬순서`` 대로 재정렬 해서 보여준다  
절렬순서는 ASC( 작은 숫자부터 ) | DESC ( 큰 숫자부터 ) ... 등이 있다


### UPDATE 테이블이름 SET 데이터명='변경할 데이터 값'
``테이블이름`` 테이블에서 ``데이터명``의 값을 ``변경할 데이터 값``으로 변경한다  
__WHERE__ 이 없으면 모든 데이터가 변경되기 떄문에 __WHERE__을 필수적으로 넣어줘야 한다

#### ~~~ WHERE 데이터명=데이터값
조건이 맞는 데이터 항목의 값만 변경한다  
보통 PRIMARY 값으로 지정하나? (id=값)

> UPDATE topic SET 데이터명1=데이터값1, 데이터명2=데이터값2 WHERE id=아이디 값

### DELETE FROM 테이블명 WHERE 데이명=데이터값
``테이블이름`` 테이블에서 조건에 맞는 항목을 제거한다  
WHERE을 작성하지 않으면 모든 데이터가 지워지기 때문에 WHERE은 꼭 넣어줘야한다 ( ㄷㄷ )


## 관계형 관련 명렁어

### SELECT * FROM 테이블명1 LEFT JOIN 테이블명2 ON 테이블명1.데이터 = 테이블명2.데이터
조건에 따라 ``테이블명1``과 ``테이블명2`` 가 합쳐진 테이블을 보여준다  
  
``데이블명1``의 데이터와 ``데이블명2``의 데이터는 같을 수 밖에 없다 ( 조건에 맞아야 하니까 )  
출력을 할 때 불필요할 수 있다 그런 경우 ``*``을 제거하고 불필요한 데이터명을 제외하고 필요한 데이터명 ( ,로 구분 )만 적어서 출력한다  
  
``테이블명1``과 ``테이블명2``이 서로 같은 데이터명을 가지고 있고 ( ex> id 값 ) 그것을 출력하려고 하면 컴퓨터 입장에서는 어떤 데이블의 데이터를 출력해야하는 지 알 수 없다  
그렇기 때문에 ``해당 테이블명``을 같이 적어야 한다 ( 데이블명.데이터명 )  
만약 그냥 데이터명이 아니라 테이블명을 확인할 수 있도록 데이터명을 변경하고 싶다면 ``AS``를 이용해서 이름을 변경하면 된다
> SELECT 테이블명1.id AS 테이블명1_id FROM 테이블명1 LEFT JOIN 테이블명2 ON 테이블명1.데이터명 = 테이블명2.데이터명;


## CHECK
### SHOW CREATE TABLE 테이블명;
CHECK 확인

### ALTER TABLE 테이블명 ADD CONSTRAINT 체크명 CHECK ( 조건 );
CHECK 추가

### ALTER TABLE 테이블명 DROP CONSTRAINT 체크명;
CHECK 제거


## 트리거
### SHOW TRIGGERS WHERE `Table` = '테이블명';
트리거 확인, 테이블명에 ``''`` 있어야 한다

### DROP TRIGGER IF EXISTS 트리거명;
트리거 삭제

#### SET PASSWORD = PASSWORD('새로운 비밀번호');
