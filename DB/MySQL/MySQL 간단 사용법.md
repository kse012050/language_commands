# MySQL ( 관계형 데이터 베이스 )
Structured Query Language - 구조화된 쿼리 언어

## 간단 명령어 사용법 ( 데이터베이스 스키마 관련 )

### SHOW {DATABASES | SCHEMAS};
데이터베이스( 스키마 ) 목록을 보여준다

### USE 이름;
``이름``으로 된 데이터베이스( 스키마 )를 사용한다

### CREATE DATABASE 이름;
사용자가 지정한 ``이름``으로 데이터베이스( 스키마 )를 생성한다

### DROP DATABASE 이름;
``이름`` 으로 된 데이터 베이스( 스키마 )를 제거한다


## 간단 명령어 사용법 ( 데이터베이스 스키마안 테이블 관련 )

### SHOW TABLES;
데이터베이스 ( 스카마 )안에 있는 테이블 목록을 보여준다

### CREATE TABLE 이름( 옵션들 - 행, PRIMARY KEY(행 이름) )
사용자가 지정한 ``이름``으로 테이블을 만든다 ( 옵션은 나중에 정리 )

### DROP TABLE 이름;
``이름`` 으로 된 데이터 베이스( 스키마 )안 데이블을 제거한다

### DESC 테이블이름;
``테이블이름`` 테이블에 있는 데이터 항목을 보여 준다

### INSERT INTO 테이블이름 ( 데이터 명 ) VALUES( 데이터 값 );
``테이블이름`` 테이블에 데이터를 넣는다.  
데이터 명 항목은 생략 가능 ( 데이터값도 생략, 즉 id 값 같이 자동으로 계산되는 값 제외 )  
테이터 값 ``NOW()``를 하면 현재 시간을 넣어준다

### SELECT 데이터명 FROM 테이블이름;
``테이블이름`` 테이블에 데이터명 값들을 보여준다  
여러개의 데이터명을 가져올 땐 ``,`` 로 구분해서 넣어주면 되고 전체를 가져올 땐 ``*``을 사용하면 된다 

> __~~~___ 물결은 위의 명령어 뒤에 이어서 붙여주면 된다

#### ~~~ WHERE 데이터명='데이터값';
``테이블이름`` 테이블에서 데이터명의 조건이 맞는 항목들을 보여준다

#### ~~~ ORDER BY 데이터값 정렬순서
``테이블이름`` 테이블에서 ``데이터명``의 데이터값 으로 ``정렬순서`` 대로 재정렬 해서 보여준다  
절렬순서는 ASC( 작은 숫자부터 ) | DESC ( 큰 숫자부터 ) ... 등이 있다


### UPDATE 테이블이름 SET 데이터명='변경할 데이터 값'
``테이블이름`` 테이블에서 ``데이터명``의 값을 ``변경할 데이터 값``으로 변경한다  
__WHERE__ 이 없으면 모든 데이터가 변경되기 떄문에 __WHERE__을 필수적으로 넣어줘야 한다

#### ~~~ WHERE 데이터명=데이터값
조건이 맞는 데이터 항목의 값만 변경한다  
보통 PRIMARY 값으로 지정하나? (id=값)

### DELETE FROM 테이블명 WHERE 데이명=데이터값
``테이블이름`` 테이블에서 조건에 맞는 항목을 제거한다  
WHERE을 작성하지 않으면 모든 데이터가 지워지기 때문에 WHERE은 꼭 넣어줘야한다 ( ㄷㄷ )
 


## 에러 정리

비밀번호를 바꿔야 한다

#### SET PASSWORD = PASSWORD('새로운 비밀번호');
